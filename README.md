# Amabile Jewels — Progetto Web Front-End

Sito web multipagina responsive sviluppato per presentare l'identità del brand Amabile, il catalogo prodotti, la biografia, gli eventi e i canali social.

## Tecnologie Utilizzate
* **HTML5**: marcatura semantica e accessibile
* **CSS3**: stile, palette colori e layout responsive
* **Validazione W3C & Accessibilità**: conformità agli standard web (documentazione inclusa nel repository)

## Pagine del Sito
* `homepage.html` — Home page e panoramica collezioni
* `biografia.html` — Storia del brand e del team
* `prodotti.html` — Catalogo e vetrina gioielli
* `eventi.html` — Eventi, pop-up store e iniziative
* `social.html` & `contatti.html` — Canali social e form di contatto
